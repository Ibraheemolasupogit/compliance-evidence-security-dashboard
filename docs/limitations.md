# Limitations

- This is an offline portfolio project using sample JSON and CSV files.
- No live SaaS, Snowflake, Azure, Sentinel, identity provider, ticketing, or cloud APIs are called.
- The sample dataset is intentionally small and designed for reviewability.
- CIS/NIST/ISO-style mappings are simplified examples for demonstration.
- Generated reports are not audit attestations and should not be treated as compliance advice.
- SLA status depends on the date when the pipeline is run.
- Future production use would require authentication, source connectors, data retention controls, access control, and approval workflows.
